# Library requirement and evidence map

Updated 16 October 2026 for the unpublished `0.2.0a2` corrective alpha candidate
(the public release is `0.2.0a1`). [SPEC.md](SPEC.md) remains authoritative. The map distinguishes implemented behavior, executable tests and
historical private live evidence. It does not claim production readiness or that
an earlier cloud result validates every subsequent repair.

[HANDOFF.md](HANDOFF.md) records the reviewed behavior; [RELEASE_RESULT.md](RELEASE_RESULT.md)
describes local validation and historical limits. Exact public source, hosted CI
and artifacts are recorded in the GitHub release's `release-record.json` and
`SHA256SUMS`. All 50 requirement IDs remain mapped below.

All live service observations below are historical 12 October evidence. They are
separate from current local and hosted code checks.

the distribution. The sanitized decision export has a separate allowlisted schema;
raw state, events and source metadata are not automatically safe to publish.

## Acceptance status

See [RELEASE_RESULT.md](RELEASE_RESULT.md) and the versioned release record for
exact code/artifact provenance, platform results, actual comparison, retained
failures and presentation. Implementation, executable tests, live synthetic
evidence and a video are distinct kinds of proof. None establishes arbitrary
executable safety or broad classification accuracy. Public GitHub release, hosted CI and PyPI publication are separate states; check
the exact versioned release record rather than inferring one from another.
